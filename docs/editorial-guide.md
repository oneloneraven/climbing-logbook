# Editorial guide

How Climbing Logbook's copy reads: help pages, app text, emails and the home page. Check new copy against it, and add a term here when a new one is settled.

## Voice

- Plain, direct and friendly. Write the way you'd explain it to another climber.
- State facts. Don't add warnings or consequences a person doesn't need to act on.
- Say what something does for the person, then how to use it.
- Promise only what we can keep. Response times are "we try to", never guarantees.
- Short sentences and common words. Explain a technical term the first time it appears on a page.

## Spelling and form

- British English. Metric units.
- Sentence case for headings, buttons and menu items, except designated terms, which keep their capitals.
- Page titles are `Name – Climbing Logbook`.
- No em dashes in new copy; use a comma, colon or full stop.

## Formatting

| Use | For | Example |
|---|---|---|
| Bold | Something to press or choose, and web addresses to go to | Choose **Save** |
| Italic | A status shown on screen, or a section of a page, and *Check our beta* in running text | The menu shows *Offline* |
| Plain | Headings, buttons, menu items, page titles and messages set by code, even when they contain a designated term | Join Check our beta |

## Terminology

| Say | Don't say | Notes |
|---|---|---|
| *Check our beta* | the beta, beta channel, beta features | The early-access channel. A designated term: italic in running text, and written in full so it can't be confused with climbing beta |
| Main Channel | regular version, main app, main site | The version at my.climbinglogbook.com, as opposed to *Check our beta*. Title case, not italic |
| Logbook Beta | | The name of the installed app for *Check our beta*. Keep as it is |
| beta (lower case) | | Climbing beta: how a climb is done. Write "your beta", as "the beta" reads like the channel |
| hardest move | crux | The hardest move/sequence field already asks for the crux, so don't ask people to mark one |
| climb | | What someone logged, in running text |
| entry | | The record of a climb, in names of actions and forms: **Delete entry**, Report this entry |
| Performance Insights | Grade Pyramid, as the umbrella | The whole group of reports, in title case. Grade Pyramid is one of them |
| My Account | My account | Title case |
| log in, sign up (verbs) | login, signup | "Sign-up" with a hyphen as a noun |
| Two-Factor Authentication (2FA) | | In full the first time on a page, then 2FA |
| Progressive Web App (PWA) | | In full the first time on a page, then PWA |
| closed beta | | Only for the invite-only period of the whole service |

## What copy never contains

- The names of our infrastructure or service providers, or how the system is built.
- Products on the boycott lists (ADR-0005). For authenticator apps, name Proton Authenticator and Ente Auth.
- Email addresses. Link to the Report an issue help page instead.
- Remarks about what the project isn't, such as whether it's a business.
- The word "groom" for refining work, in anything.
